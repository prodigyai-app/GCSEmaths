# Prodigy Edexcel GCSE Maths

The established lessons and 18 original 80-mark papers are supplemented by focused depth lessons with explanations, worked examples, reconstructed working, independent practice and indicative mark schemes. specification-map.json maps all 97 numbered content statements to lesson destinations; it is a revision navigation map, not an exam-board endorsement or a substitute for teaching.

Foundation / Higher buttons persist the chosen tier. Foundation hides Higher-only lessons, labelled examples, scaffolded activities and exam parts. Higher includes the shared content. Switching tier preserves answers and recomputes completion against the visible questions. Full practice papers remain separate by tier, with Paper 1 non-calculator and Papers 2 and 3 calculator.

Depth sources are depth-course.json and gcse-depth.js; update the lesson links in specification-map.json when changing destinations, then rebuild the browser data with node scripts/build-depth.cjs. The shared Maths keyboard supports powers, roots, fractions and saved working.
